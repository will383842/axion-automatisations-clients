# Signaler une faille de sécurité

Merci de **ne pas** ouvrir de ticket public pour une faille.

Utilisez le signalement privé de GitHub : onglet **Security** → **Report a vulnerability** de ce dépôt.

Nous accusons réception sous 3 jours ouvrés et vous tenons informé(e) de la correction. Aucune donnée réelle de client ne se trouve dans ce dépôt ; si vous pensez en avoir trouvé une, signalez-le immédiatement par ce même canal.
